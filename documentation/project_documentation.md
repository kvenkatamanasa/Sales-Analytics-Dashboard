# Sales Analytics Dashboard

## Project Overview

An end-to-end Sales Analytics project using MySQL, Excel, Power BI, and SQL to analyze sales performance and generate business insights.

## Tools & Technologies

- MySQL
- SQL
- Microsoft Excel
- Power BI
- DAX
- Power Query

## Dataset

The project uses a cleaned sales dataset containing sales transactions and business-related information.

## Data Preparation

- Imported the cleaned CSV dataset into MySQL.
- Converted date values into the appropriate date format.
- Cleaned numeric fields such as sales, cost, profit, unit price, and discount.
- Checked data quality and missing values.
- Prepared the dataset for SQL analysis and Power BI visualization.

## SQL Analysis

SQL was used to analyze:

- Overall sales performance
- Quantity sold
- Category performance
- Regional performance
- Product performance
- Customer performance
- Profitability
- Monthly sales trends

## Power BI Dashboard

The Power BI dashboard provides:

- Sales KPIs
- Profit KPIs
- Quantity analysis
- Regional analysis
- Category analysis
- Product analysis
- Monthly sales trends
- Interactive filters

## Project Workflow

CSV Dataset
→ Data Cleaning
→ MySQL
→ SQL Analysis
→ Power BI
→ Dashboard
→ Business Insights

## Business Objective
The objective is to transform raw sales data into meaningful insights that help understand sales performance, profitability, regional trends, product performance, and customer behavior.
